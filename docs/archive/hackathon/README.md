# The hackathon (27 September 2026)

Rundown, then called Brainstorm, was built in about three hours on 27 September 2026 at the GOMYCODE × NVIDIA "Come Build with AI" hackathon, and took 3rd place in Senegal. These files are the plans, notes and numbers from that day. The repo exactly as it stood at the deadline is the git tag `hackathon-submission`: that is the judged state. Nothing in this folder is maintained, and parts of it describe features that were cut or changed since.
