Your code
stays yours.

It runs on your machine and reads your agents' logs where they are. No account, no cloud. Secrets are masked before anything is stored, and nothing goes to Claude unless you ask.

Install it in
Claude Code.

Free. Everything runs on your machine.

claude
/plugin install brainstorm --marketplace Djbrl/brainstorm

✻Start a new session. Rundown starts in the background with it.

/brainstorm:open

✻The map opens in your browser, for the project you're in.

On an older Claude Code: /plugin marketplace add Djbrl/brainstorm, then /plugin install brainstorm@brainstorm.

You need Claude Code and Node.js 22.13 or later.
