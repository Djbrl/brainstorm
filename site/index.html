The product

Follow. Ask. Zoom out.

Three views that sit next to your agent. Claude Code runs the agents; Brainstorm shows you what they did, where, and lets you question it.

01 · Follow

Every agent step, labeled.

A live timeline of a Claude Code session: prompts, actions and code edits, each with a short plain-English label.

  • Click any edit to see its diff
  • Ask “why did you change this?” and get a grounded answer, with its cost shown
  • Risky edits are flagged: deleted tests, auth or env files, large deletions
02 · Map

Your codebase, glowing where agents work.

Modules and files as a graph, with imports as lines. Nodes glow by how recently they changed and pulse where an agent is editing right now.

  • Click a node for its summary and recent steps
  • Point it at any existing repo, not only agent-written code
03 · History

Watch your project grow.

Every map is saved as a snapshot. Drag the slider to see how the codebase took shape, turn by turn.

How it works

The right model for each job.

Most of Brainstorm needs no AI at all. Where it does, each model does what it's best at.

Nemotron 3 Nano · NVIDIA Brev

Reads everything

The bulk work: a summary for every file and module, a label for every agent step, risk flags on edits. Runs on our own GPU with vLLM, at a flat hourly cost.

Claude

Answers “why?”

Gets a small, grounded package: your question, the step and its diff, the steps before it, the file and module summaries. Falls back to Nemotron if it's down.

No AI

The map itself

The timeline, the import graph, recency heat and history come straight from the agent's logs, the file system and git. Fast, exact, free.

Built on NVIDIA Brev

One open model, our own GPU, several jobs.

NVIDIA Nemotron 3 Nano runs on a Brev GPU through vLLM. It reads the whole codebase, labels every agent step and flags risky edits. Because it's our own GPU, it's also Brainstorm's private mode: your code never has to leave it.

Privacy & control

Your code stays yours.

Local-first

Sessions, maps, summaries and answers are stored in one SQLite file on your machine.

Secrets masked

API keys, tokens and passwords are redacted before anything is stored or sent.

Small packages

Questions send only the step, its diff and short summaries, to the provider you already use, with your own key.

Private mode

Run all the reading on your own GPU. A human stays in control: follow, ask, pause.

Built with itself

Brainstorm watched its own build.

We built Brainstorm today with several Claude Code agents working in parallel, and Brainstorm followed every one of them. The map in our demo is our own codebase, growing.
