Your code
stays yours.

It runs on your machine and reads your agents' logs where they are. No account, no cloud. Secrets are masked before anything is stored, and nothing goes to Claude unless you ask. Once a day it sends anonymous usage counts, never your code; one click in Settings turns that off.

Install it in
Claude Code.

Free. Everything runs on your machine.

claude
/plugin install rundown --marketplace Djbrl/brainstorm

✻Start a new session. Rundown starts in the background with it.

/rundown:open

✻The map opens in your browser, for the project you're in.

On an older Claude Code: /plugin marketplace add Djbrl/brainstorm, then /plugin install rundown@rundown.

You need Claude Code and Node.js 22.13 or later.

What's next.

Rundown is a prototype today. The full release lands in late October.

Today

Prototype, version 0.5

  • A live map of your agents, and a replay of every thread
  • The Track: every step beside the map, failures in red
  • Places: the websites and apps each thread used, on a map. Click one to see the step.
  • Waiting for you: a notification when a thread needs you
  • Share a thread as a web page or Markdown
  • A plugin for Claude Code

Late October

Full release

  • Codex threads on the same map as Claude Code
  • Files changed by commands (sed, scripts, redirects) count as edits
  • A first read on NVIDIA Nemotron: a short summary of every file and every step
  • A recap of what happened while you were away
  • Let your agents interact with Rundown through MCP and CLI

After

What we're building toward

  • Support for Cursor and Gemini CLI
  • Agents that warn each other before editing the same file
  • Replays on pull requests
  • Pause and steer an agent from the map
