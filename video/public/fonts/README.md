# Typography

Cabinet Grotesk 700/800 for headlines; Satoshi 400/500 for supporting copy and UI.

Official families:
- https://www.fontshare.com/fonts/cabinet-grotesk
- https://www.fontshare.com/fonts/satoshi

License: ITF Free Font License 2.0 (17 Aug 2026), read on 27 September 2026:
https://www.fontshare.com/licenses/itf-ffl

The fonts permit use in videos and self-hosting for the licensee's own project. The font files themselves must not be redistributed through a public repository. The binaries are locally cached and gitignored. Anyone cloning this project should obtain their own copies from Fontshare. No modifications, conversions, or subsetting have been performed. `fontshare-source.css` preserves the official CDN URLs. `../../download-fonts.sh` downloads those original files; run from the repository root with `sh video/download-fonts.sh`.

Remotion awaits all four used faces with FontFace + delayRender before rendering any frame, so export does not depend on external network access.
